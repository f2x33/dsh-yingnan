# 05 · 定妆图比例回退（回到最初那档 ≈3.2，站位保持现在这版）

> **为什么有这一份**：中间为了"更 Q"把比例从 3.16 一路压到 2.37，
> 结果是**头太大、身体像根管子**。用户看过四联对比后确认：
> **最初那档比例（豆包原图 3.21 / 本包早期 3.16）才是想要的**，
> 站位/设计保持现在这一版（站立、剑斜向下持在身侧、外杏黄内白、下摆垂落）。
>
> **这一轮只改比例**：**把头缩小、身体与腿拉长**，回到正常动漫少女比例（身高/头宽 ≈ 3.1~3.3）。
> 其余（姿态、服装分层、赤红剑、垂落、纯绿背景、画风）**一个字节都不动**。
>
> ⚠ 与 `docs/04` 的方向**正好相反**：04 是"放大头/缩短身体"，这一份是"缩小头/拉长身体"。
> 所以这一份里**不写**任何"两头身/Q 版"的要求，否则模型会两个方向打架。
>
> **怎么用**（¥0.2）：
>
> ```powershell
> node tools\gen-api.mjs --docs docs\05-比例回退提示词.md --only 定妆图-比例回退原版 --still-only --skip-name-gate
> $env:ARK_API_KEY = "你的key"
> node tools\gen-api.mjs --docs docs\05-比例回退提示词.md --only 定妆图-比例回退原版 --still-only --skip-name-gate --go
> ```
>
> 出图后量一下：`node tools\measure-proportion.mjs out\_stills\定妆图-比例回退原版.jpg`
> （看「头宽(连续)」那行，目标 3.1~3.3），满意再另存为 `out/定妆图.png`，
> 然后 `node tools\make-placeholder.mjs --force --install`。

#### 001. `定妆图-比例回退原版`

**① 图生图**（上传 `out/定妆图.png` 当输入）

```text
【输入】我上传的这张角色定妆图。
【任务】保持这个角色的**姿态、姿势、服装、剑、背景、画风全都不变**，
只把**人物比例改回正常动漫少女的比例**；背景仍是纯绿色。

【必须保持不变（一项都不许动）】
站姿与朝向：正面偏侧身站立、双脚并拢、重心落在双脚上；
右手的持剑方式与剑的角度：**剑斜向下持在身体一侧，剑尖朝下或斜前下方**（不要举起来、不要改变角度）；
五官、脸型、瞳色、眼型、发型与发丝走向、白玉簪；
杏黄外袍 + 白色内衬的两层结构、淡金云纹、丝绦、白布云鞋；
**赤红剑身（无任何火焰 / 光晕 / 发光特效）**；
下摆、丝绦与长发**自然垂落**的状态；纯绿背景；画风与线条笔触。
不允许重新设计、不允许美化、不允许换风格、不允许增减配饰。

【唯一要改的一处：人物比例 —— 按下面的换算调，别调过头】
现在这一版**头偏小、身体偏长**（量出来约 3.6 个头高），要往回收一点：
- **把头（含头发、发髻）再放大到当前的约 1.08 倍**；
- 同时把**脖子以下的身体（躯干 + 腿）再压缩到当前高度的约 0.97 倍**；
- 改完之后：**身高 ÷ 头宽 ≈ 3.1~3.3**（约三个头高），**腿仍然明显长于头高**；
- **不要回到"两头身"的大头 Q 版**（那是上一版的问题），也不要写实成年人；
- 整个人在画面里的位置与占高基本不变、脚底位置不变。

【画面与背景】
角色全身入镜，脚底位于画面下方约 91.7% 的位置；角色横向居中，宽度约占画面的 30%~60%；
背景纯绿 #00FF00，干净、无渐变、无阴影、无地面、无其他物体或杂物；脚下也不要画接地阴影；
画面里不要出现任何文字、字幕、水印、logo、边框、分镜格、签名。

【最后再强调一次】
**只改比例**（头缩小、身体与腿拉长，回到约三个头高的正常动漫少女比例），
**站姿、持剑姿势与角度、服装、剑的颜色与特效、垂落状态、背景、画风全部保持不变**。
```
