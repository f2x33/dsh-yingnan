# 02 · 动作提示词（余英男 · 图生图 → 图生视频）

> 本文档是 `dsh-yingnan` 的动作提示词（**当前 19 段**；角色：蜀山派余英男，桌面上/设置面板里的显示名是 **蜀山侠女**）。
> 先用定妆图生成该动作的绿幕静止帧（① 图生图），再把这张静止帧当首帧生成短视频（② 图生视频）。
>
> **动作名必须逐字一致**（中文、连字符、「-」都要对）。这些名字是 `assets/config.jsonc`
> 里写死的键，改一个字就会出现「右键菜单里有名字、点了没反应（404）」。
> `node tools/selftest.mjs` 会把**配置里的名字**与磁盘素材逐字对照。
>
> **必须先有定妆图**：按 `docs/01-定妆图提示词.md` 得到 `out/定妆图.png`
> （身高/头宽闸门 ≤ 2.1；本包现用定妆图实测 1.87），再拿它当输入跑这些段。
> 角色与比例全部继承定妆图，定妆图错了这些段会一起错。
>
> ⚠ **比例红线**：每一段生成出来都必须是**约 2 个头高**的超变形 Q 版（身高/头宽 ≤ 2.1）。
> 动作段最容易在这里翻车（实测第一批：15 张里 13 张跑成了 2.7~3.4 的正常少女比例）。
> 出图后**每张都要过** `node tools\measure-proportion.mjs <图>`，不合格就重出那一张。
>
> **背景必须纯绿 `#00FF00`**（橄榄绿不行），方便后续抠像成透明 webm。
>
> **生成时关掉水印 / 字幕 / logo**。画面里不允许出现任何文字、字母、数字、水印或签名。
>
> **剑是赤红剑身、但剑周围不要任何火焰特效**（火舌/火星/光晕/发光边缘/拖影都不要）——
> 半透明的光晕抠像后会糊成一团，所以颜色是"火焰剑"、画法上没有任何火焰。
>
> **衣摆 / 衣带 / 长发的物理要符合常规**：站立、待机、参悟、等待这类**静止**姿势里，
> 它们**自然垂落**（顺着重力垂下，不要无风自飘、不要扬在半空）；
> 只有真的在动的时候才飘 —— 御剑飞行（向后飘）、工作状态-舞剑 / 拔剑 / 御剑突进 / 挥手（随动作扬起）。

> ⚠ **当前包里的素材是零成本占位素材**（由定妆图静态抠像生成，只为把骨架跑通，画面不会真动）。
> 真素材按本文档生成后**同名覆盖**即可 —— 配置一个字都不用改，覆盖与体检命令见最后一节。

## 二、全部提示词

#### 001. `待机呼吸休闲`

> 待机：呼吸起伏，首尾无缝循环；**空手自然站立（不握剑、不持任何道具）**

**① 图生图**（上传定妆图 → 得到这一段的绿幕静止帧）

```text
【输入】我上传的这张角色定妆图。
【任务】保持这个角色的**设计与长相完全不变**，输出同一角色的一张新图：换成本段要求的姿势，并把背景换成纯绿色。

【人物必须严格保持不变】
角色的五官、脸型、发色与发型、瞳色、服装款式与配色、身体比例、画风与线条笔触——
全部与输入图一致，不允许重新设计、不允许美化、不允许换风格、不允许增减配饰。

【背景必须替换】
原背景不要保留，整幅背景替换为纯绿色（要求见下）。

【这一帧的姿势】
自然站立，**双臂放松垂在身体两侧、双手空着自然放松**，双脚并拢，正面朝向镜头；**外袍下摆、丝绦与长发自然垂落**；**绝对不要握剑、不要抱或拿任何东西 —— 不要剑、不要卷轴、不要任何道具**；表情平静温和，带着一点剑侠随时听令的沉静。

【画面要求】
纯绿色背景，色值 #00FF00，背景干净、无渐变、无阴影、无地面、无其他物体或杂物；
**脚下也不要画接地阴影或投影 —— 脚踩的位置也必须是纯绿色**；
角色全身入镜，脚底位于画面下方约 91.7% 的位置；
角色横向居中，宽度约占画面的 30%~60%；
不要出现文字、字幕、水印、logo、边框、分镜格；
【比例红线 —— 这一条最容易画错，画错就重画】
这是**超变形 Q 版**：整张图从头到脚**只有大约 2 个头高**（身高 ÷ 头宽 ≤ 2.1）；
头要大、脖子几乎看不见、身体要短、腿要短，**腿绝不能比头长**；
衣摆与头发可以往下延伸，但**身体本身必须是短圆的 Q 版比例**；
如果画成"腿比头还长的正常少女"，就是画错了，必须按 Q 版重画。
【画风】与输入图完全一致的画风，线条干净，色彩鲜明，不要写实化，不要改变笔触。
```

**② 图生视频**（上传 ① 得到的那张图当首帧）

```text
【输入】我上传的这张图，就是本视频的第一帧。
【任务】画面内容保持完全不变，只让角色动起来，生成一段视频。

【这段视频里做什么】
原地待机，身体随呼吸轻微起伏，重心极缓慢左右微移，**双臂全程自然垂在身体两侧、随呼吸轻摆**（不要抬起、不要握或拿任何东西）；**外袍下摆、丝绦与长发自然垂落**，只随极轻微的重心移动有一点点摆动（不要飘起来、不要扬在半空）。首尾姿态必须完全一致，可无缝循环。

【本段特别要求】循环播放，首尾必须无缝；**画面里不要出现剑或任何道具，双臂始终垂在身体两侧**

【画面要求】
背景始终是纯绿色 #00FF00，不要改变背景，不要添加任何景物、地面或阴影；
镜头完全固定：不推拉、不旋转、不缩放、不移动；
角色始终居中、脚底位置不移动（移动类动画除外：原地做动作，不要真的走出画面）；
不要出现文字、字幕、水印、logo、边框；
**不要改变人物的头身比**（进视频后必须和首帧完全一致：Q 版大头短身，不许把身体拉长、不许变正常比例）；
动作幅度适中，不要快速变形或闪烁，主体边缘保持清晰。

【时长】10 秒，24 或 30 fps。
```

```text
这是**超变形 Q 版**：整张图从头到脚**只有大约 2 个头高**（身高 ÷ 头宽 ≤ 2.1）；
头要大、脖子几乎看不见、身体要短、腿要短，**腿绝不能比头长**；
衣摆与头发可以往下延伸，但**身体本身必须是短圆的 Q 版比例**；
如果画成"腿比头还长的正常少女"，就是画错了，必须按 Q 版重画。
【画风】与输入图完全一致的画风，线条干净，色彩鲜明，不要写实化，不要改变笔触。
```

**② 图生视频**（上传 ① 得到的那张图当首帧）

```text
【输入】我上传的这张图，就是本视频的第一帧。
【任务】画面内容保持完全不变，只让角色动起来，生成一段视频。

【这段视频里做什么】
环绕的剑影**缓慢旋转一周**（彼此保持等距、朝向随旋转变化，**不要糊成光团、不要变成火焰**），脚下的剑气泛起一层淡淡的光晕（**不要画接地阴影**）；人物本体基本站定、随呼吸起伏，衣摆与发丝持续轻扬；首尾姿态一致，方便循环。

【本段特别要求】随机小动作；剑影必须是**「边缘清晰、半透明的剑形」**，数量 4~6 柄、等距环绕，**绝对不要火焰 / 火星 / 烟雾 / 爆炸**，也不要糊成光团；**人物本体保持清晰不透明**；**脚下不要画接地阴影**；

【画面要求】
背景始终是纯绿色 #00FF00，不要改变背景，不要添加任何景物、地面或阴影；
镜头完全固定：不推拉、不旋转、不缩放、不移动；
角色始终居中、脚底位置不移动（移动类动画除外：原地做动作，不要真的走出画面）；
不要出现文字、字幕、水印、logo、边框；
**不要改变人物的头身比**（进视频后必须和首帧完全一致：Q 版大头短身，不许把身体拉长、不许变正常比例）；
动作幅度适中，不要快速变形或闪烁，主体边缘保持清晰。

【时长】10 秒，24 或 30 fps。
```

## 三、生成顺序与自检

1. 按 `docs/01-定妆图提示词.md` 出定妆图，先量比例（身高/头宽 ≤ 2.1）再往下走。
2. 每一段先跑 ① 图生图，拿到绿幕静止帧；再拿这张帧当首帧跑 ② 图生视频。
3. 本文档的 19 个动作名与 `assets/webm/` 里的文件名必须**逐字一致**（`node tools/selftest.mjs` 会查）。
4. 背景一律纯绿 `#00FF00`，画面里不允许有任何文字，水印与 logo 生成时全部关掉。
5. 真素材生成完，**同名覆盖**即可（配置不用改）：

   ```powershell
   node tools\keyscreen.mjs --in out\raw --out out\webm   # 绿幕 → VP9-alpha webm
   node tools\pipeline.mjs                               # 拷进 $DSH_HOME\dsh-yingnan\main-animation\webm\ + 体检
   ```

   > `keyscreen.mjs` / `pipeline.mjs` 的增量判断是「输出存在就跳过」，重做某段别忘了 `--force`。
   > **抠像阈值别照抄父包**：本包定妆图的绿幕是 `rgb(33,171,75)`（不是亮纯绿），
   > 用父包默认的 `colorkey 0.3/0.1` 会把**深色头发抠成半透明**（看着像白发）。
   > 实测 `--similarity 0.12 --blend 0.02` 才干净；`make-placeholder.mjs` 已把这条写进默认值 + 质量闸门。
