## 二、现状与下一步（这一步之前，别再生成动作）

**已经有**：定妆图 `out/定妆图.png`（1696×2576 竖版）、比例实测 2.37 ✅。

**还没有**：真素材。本包现在那 **15 段 webm 是零成本占位素材**，来源是
`tools/make-placeholder.mjs` —— 把定妆图抠出主体、缩放到与父包素材同框比例，放到 640×360 画布上（0 元、0 次 API 调用）。
**它们不是动作，只是"能播的静帧"**，用来先把插件链路跑通、把动作池配好。

下一步就是把这 15 段换成真素材，用**本包 `tools/` 里有的**脚本（照 `docs/03` 的实测记录走）：

```powershell
cd D:\2.dsh\1.红队版数字人\dsh-yingnan
$env:ARK_API_KEY = "你的key"

node tools/gen-api.mjs --probe --go                                     # ① 验模型（失败不花钱）
node tools/gen-api.mjs --limit 2 --resolution 480p --duration 5 --go    # ② 只跑 2 段肉眼验收（约 ¥9）
node tools/pipeline.mjs                                                 # ③ 抠像 → 装包 → 体检
node tools/gen-api.mjs --all --resolution 480p --duration 5 --go        # ④ 确认无误再全量（约 ¥44）
node tools/pipeline.mjs
```

生成时记住三条：**纯绿底 `#00FF00`**、**全身入镜（脚底 ≈ 91.7%）**、**关水印**。
（`--resolution 480p --duration 5` 是省钱口径：最终素材只有 640×360，480p 完全够。）

```text
【多图参考分工必须看清】
第一张：余英男的 Q 版基准立绘 —— 这是**人物长相、发型、人物比例、画风**的唯一标准。

不要参考它的姿势与构图、不要把它背景里的任何文字、水印或图案放到画面里。

【第一优先：人物比例，这一条压倒其他所有要求】

衣摆：**衣摆下缘有淡金色云纹**（云纹只做点缀，不要满身、不要满身花纹、不要任何文字）。
腰：一条**杏黄丝绦**在腰间松松系住，垂下一小段。
```

## 八、文字与水印：为什么必须零（留个底）

**问题**：桌宠播放 `东张西望` 和移动类动画时会**整体镜像翻转**（面朝左 / 朝右切换）。
画在**素材像素里**的字一翻转就变反字；水印更糟 —— 它既是"字会变反"，又是"画面里多了个脏东西"。
dsh-pet 的 `noMirror` 只能按**动画分类**屏蔽，而水印出现在**所有**动画里 —— 插件层修不了。

**做法**：
1. 提示词里写死「零文字、零水印、零 logo」；
2. 本体（道袍、飞剑、白玉簪）上**不画任何文字**，云纹只做纯装饰图形；
3. 模型自加的水印（本版现图右下角那行**「豆包 AI 生成」**）用 `find-watermark.mjs` 拿坐标、
   `keyscreen.mjs --mask` 盖掉。**本版现图实测掩膜：`--mask 1626,2477,39,71`**（画布 1696×2576，
   包围盒 1624,2485-1656,2539；框的左边界被顶到人物右边界，避免削到角色）。

## 九、关于飞剑的取舍（为什么保留）

- **保留**（当前决定）：剑修的辨识度全靠它，一眼可辨；剑身虽然是赤红色（带一点高光），但轮廓是硬边，
  属于好抠的一类（**真正的绿边百分比要等 `keyscreen.mjs` 跑完才算数，本包目前还没跑过真素材**）。
- **代价**：15 段里有不少"双手要动"的动作（挥手、鼓掌、抱头之类）。
  定妆图手里有剑，那几段可能保留剑、或者出现"拿着剑挥手"的怪姿势 —— 属于观感瑕疵，不影响能不能用。
- **天然不搭的**：如果哪一段写的是"双手敲键盘 / 敲桌面"，本版手里是剑，那几段会最突兀 ——
  要么改用下面的无剑备选，要么生成那几段时用 `gen-api.mjs --ref <一张无剑定妆图>` 单独换参考图。

## 十、设计说明（保留的元素为什么留）

- **乌黑长发 + 一支白玉簪**：发饰只有这一件，素到底；Q 版尺寸下"黑发 + 杏黄外袍 + 白色内衬 + 一点红剑"对比最强，
  抠像后轮廓也干净（不像碎发箍、珠串那样一堆碎边）。
- **杏黄交领外袍 + 白色内衬中衣**：你指定的服装。白色在深色页面背景上做桌宠反而最跳；
  整块白面比碎花、比多色拼接都好抠。
- **袖口 / 衣摆的淡金云纹**：把大片杏黄切开，避免在 Q 版尺寸下糊成一片黄，同时点出"蜀山剑修"。
- **杏黄丝绦 + 白布云鞋**：同色系收口，不抢视线。
- **赤红长剑**（不发光、无火焰特效）：全身唯一的强色，是视觉焦点，也是"剑修"这层身份的唯一来源。
- **干净利落的国风 Q 版插画**：素材最终只有 640×360，写实厚涂的细节会全部糊掉 ——
  干净的线条与色块才是有效信息。

## 十一、这套提示词的方法论（将来自己改时照抄）

1. **比例给数字 + 开头给 + 中途自检 + 结尾复述**（三道压制，一道都不能省）。
   父包 v1 是数值写错（"三头身" → 3.26），v2 是被服装细节稀释（只写一道 → 2.73），
   v3 起三道齐上才稳定拿到 2.00 / 1.94；本版 2.37。
2. **多图参考必须写明分工**。只说"参考这两张"，模型会把成人比例、写实画风、背景文字一起抄进来。
3. **服装/道具参考图要先裁干净**（父包的做法：`out/style-ref/红队工装参考.png` 已切掉标题文字和水印）。
4. **改完一定要量**：`measure-proportion.mjs` 的「判定」行 + `side-by-side.mjs` 并排图，两分钟出结论；
   转码后再看 `keyscreen.mjs` 报的**绿边百分比**（> 0.5% 就调 `--similarity`）。
5. **常驻道具不要写进负面词**；不要的旧元素（旧服装、旧道具）才写进去 ——
   本版就是"飞剑不写、旧红队工装写"。
