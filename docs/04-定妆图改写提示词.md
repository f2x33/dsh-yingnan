# 04 · 定妆图改写提示词（调头身：头略收 + 身体变敦实 + 垂发收拢）

> **用途**：上一版把比例压到了 2.37（连续段口径），但**头显得太大** ——
> 因为迭代时只做了"放大头 / 压缩身体"，身体被压成了**细长的柱子**，
> 头（含蓬开的垂发）就显得过分巨大。父包那只红队宠物是**敦实的短板身材**：
> 肩宽、袖子蓬松、下摆像钟形展开，头虽然大但被身体的体量托住了。
>
> **这一轮改三处**（其余一切不动）：
>   ① 头（含发髻）**缩小**；
>   ② 身体**加宽加厚**：肩更宽、袖子更蓬、外袍下摆像钟形展开、躯干有厚度 —— 目标是**敦实**，不是细长；
>   ③ 两侧长垂发**收拢贴近身体**，不要向外大幅蓬开、不要比身体宽出一大截。
>
> ⚠ **比例底线仍要守**（头大身短是这只宠物的底色），只是**别让头一家独大**：
> 身高/头宽按 **≤ 2.4**（a 版）/ **≈2.3~2.6**（b 版）要求 —— 上一版 2.37 是"头占一半"，这一轮要"头大、但有体量托住"。
>
> **怎么用**（两条一次出，共 ¥0.4）：
>
> ```powershell
> # 空跑（0 元）
> node tools\gen-api.mjs --docs docs\04-定妆图改写提示词.md --only 定妆图-调头身a,定妆图-调头身b --still-only --skip-name-gate
> # 真跑（¥0.4）
> $env:ARK_API_KEY = "你的key"
> node tools\gen-api.mjs --docs docs\04-定妆图改写提示词.md --only 定妆图-调头身a,定妆图-调头身b --still-only --skip-name-gate --go
> ```
>
> 出图后逐张过闸门（比例用工具量，"身体体量"要肉眼看）：
> `node tools\measure-proportion.mjs out\_stills\定妆图-调头身a.jpg`
> 挑中的那张另存为 `out/定妆图.png`，再重跑 `node tools\make-placeholder.mjs --force --install`。

#### 001. `定妆图-调头身a`

**① 图生图**（上传 `out/定妆图.png` 当输入 → 头 ×0.90）

```text
【输入】我上传的这张角色定妆图。
【任务】保持这个角色的**设计与长相、服装、剑、背景都不变**，只调整**体型与头发的蓬度**；背景仍是纯绿色。

【必须保持不变】
五官、脸型、瞳色、眼型、乌黑长发（长度与发丝走向）、白玉簪、杏黄外袍 + 白色内衬的两层结构、
赤红剑身（无任何火焰 / 光晕 / 发光特效）、剑斜向下持在身侧、白布云鞋、下摆与长发自然垂落、
纯绿背景、画风与线条笔触。不允许重新设计、不允许美化、不允许换风格、不允许增减配饰。

【这一轮要改的三处】
① **头（含发髻）缩小到当前的约 0.90 倍** —— 头仍然明显比常人大（这是 Q 版的底色），
   但不要让头部占到整个人高度的一半。
② **身体加宽、加厚，做成"敦实"的短板身材**（这是本轮重点）：
   肩膀更宽更圆、**袖子明显更宽更蓬松（宽袍大袖）**、外袍下摆像**钟形向外展开**、
   躯干有厚度和体积感；**绝对不要把身体画成细长的柱子**，也不要细腰长腿。
   参考感觉：像一只略扁的、圆滚滚的小坛子，而不是一根筷子。
③ **两侧长垂发收拢、贴近身体**：不要向外大幅蓬开、不要横向铺得比身体宽出一大截；
   头发可以有厚度，但整体轮廓要收在身体附近。

【比例与构图（仍要守住）】
头大、身短是这个角色的底色：**身高 ÷ 头宽 ≤ 2.4**；
**腿很短**（腿长明显短于头高）；脖子几乎看不见；眼睛极大。
角色全身入镜，脚底位于画面下方约 91.7% 的位置；角色横向居中，宽度约占画面的 30%~60%。
**最后再强调一次**：这一轮是**"头略收、身体变敦实、垂发收拢"**，不要改变五官 / 服装 / 剑 / 背景；
**身体必须显得有体量、圆润厚实，绝不能是细长柱子。**

【背景与画风】
背景纯绿 #00FF00，干净、无渐变、无阴影、无地面、无其他物体或杂物；**脚下也不要画接地阴影**。
画风与输入图完全一致：线条干净、色彩鲜明，不要写实化、不要改变笔触。
画面里不要出现任何文字、字幕、水印、logo、边框、分镜格、签名。
```

```text
【这段视频里做什么】

【画面要求】
背景始终是纯绿色 #00FF00，不要改变背景，不要添加任何景物、地面或阴影；
镜头完全固定：不推拉、不旋转、不缩放、不移动。

【时长】10 秒，24 或 30 fps。
```
